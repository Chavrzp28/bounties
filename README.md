# XPR Network Bounties — Archived

## Status

This repository is archived. The XPR Network bounty structure, historic listings, and prior submissions are under review.

There are currently **no open bounties** and the program is not accepting new claims, proposals, or work against the historic bounty descriptions.

## Why this repository is archived

The historic bounty listings no longer provide a reliable statement of current priorities, technical requirements, ownership, or reward terms. Rather than leave outdated offers available for claim, they have been removed from this repository while the program is reviewed.

The review includes:

- whether a bounty program will resume;
- which work remains strategically useful and has a current technical owner;
- delivery, security, maintenance, and acceptance requirements; and
- claim, payment, and governance processes.

If a future program is launched, it will be announced through an official XPR Network channel with current terms and a new or updated repository.

## Historic record

Existing issues, pull requests, and commits remain available as a public historical record. They do not constitute active bounty offers or approval of any claim.
